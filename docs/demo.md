# 실제 시연 자료

<img src="../assets/mobile-consultation-demo.png" width="300" alt="SleepWell 모바일 상담 화면">

[모바일 음성상담 영상](../assets/mobile-consultation-demo.mp4)은 기존 프로젝트 파일입니다. 50.165초, 576×1280, 1,561,752bytes이며 원본을 변경하지 않은 복사본입니다. 화면캡처는20초 지점에서 추출했습니다.

| 구간 | 보여주는 동작 |
|---|---|
| 0–8초 | 마이크 입력·음성 처리 표시 |
| 8–27초 | 전사된 질문과 첫 답변, 재생 UI |
| 27–41초 | 후속 질문 입력·처리 |
| 41–50초 | 후속 상담 답변과 재생 UI |

1초 간격 전체 구간 프레임 및 주요 전환의 원해상도 화면을 검토했고, 로컬 자동 음성 전사로 앱의 상담 TTS 내용을 확인했습니다. 검토한 화면/전사에서 얼굴·실명·전화·계정·비밀키를 발견하지 않았습니다. 개인정보가 포함된 학교 보고서 원본은 공개하지 않았습니다.

이 영상은 UI·질문 전사·상담 응답·재생 상태의 동작 근거입니다. 검색 trace나 citations가 보이지 않으므로 특정 backend commit의 RAG 실행, 모델 버전, 검색 정확도, 처리 속도 측정의 증거로 쓰지 않습니다. 영상에서 보이는 일반 상담 문구는 의료 효과 검증이 아닙니다.

Java API의 이번 검증은 별도의 합성 단위 테스트입니다. 당시 자료의 시연과 2026 검증 결과를 혼합하지 않습니다.
