# 공개 자료 범위

사용자가 이번 포트폴리오 작업에서 팀 프로젝트 소스 공개를 허용했습니다. 현재 backend의 필요한 Java 소스·build/config 예시, 초기 Python 프로토타입, 검토한 모바일 시연과 분석/테스트를 포함합니다. 원본 팀 소스가 모두 개인의 단독 구현이라는 뜻은 아닙니다.

제외: 원본 Git history와 `.git`, 비밀키/토큰/실환경 파일, 타인 실명·전화·학번·서명이 포함된 학교 보고서, 원설문/건강 기록, 저작권·재배포 조건이 확인되지 않은 PDF corpus, 벡터/index, 체크포인트, 실행 JAR/APK, 가상환경·개인 PC 캐시, 원본배포계정과 원로그.

과거 commit을 다시 만들거나 저자를 바꾸지 않았습니다. 팀 전체 history를 이 repository에 merge하지 않습니다. [source manifest](source-manifest.json)의 원본 hash로 출처를 기록하고 현재 작업을 새 commit으로 남깁니다.

별도 명시적 라이선스가 없는 원본 팀 코드를 임의로 MIT/Apache로 재라이선스하지 않았습니다. 공개 열람과 자유 재배포 라이선스 부여는 같은 의미가 아닙니다. 외부 dependency의 권리는 각 프로젝트 라이선스를 따릅니다.
